# Terminology and mechanics reference

This developer reference maps presentation-neutral identifiers to the mechanics used for implementation and audit. Player-facing themes use original names, original descriptions, and original geometric SVG assets. Names and images never select or change rules.

Mechanics reference: [publisher second edition rules](https://www.riograndegames.com/wp-content/uploads/2016/09/Dominion2nd.pdf). This project is independent and is not endorsed by the publisher. Original artwork and rulebook/card prose are not redistributed. This approach reduces intellectual-property exposure without asserting legal clearance.

## Intentional differences

- Solo human play uses one to three automated opponents; human multiplayer is deferred.
- Theme prose paraphrases mechanics. The engine follows the referenced second edition rules; there are no intended card-rule deviations.
- Local games save each accepted choice. Replaying saves preserves decisions, effects and randomness.
- The interface records public history and each human player’s private observations; it does not reveal another player’s private information.

When changing mechanics, add a dated explanation and source here. When adding a theme, retain stable IDs and update this mapping.
